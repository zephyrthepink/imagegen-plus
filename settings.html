One-time profile bridge setup
  1. Download the profile bridge and extract it into your SillyTavern root folder.
  2. Set enableServerPlugins: true in SillyTavern's config.yaml.
  3. Restart SillyTavern and reload this page.

The bridge keeps the saved key on the server while forwarding image requests.

Scene sources

For example, set 5 to use the last five conversation messages. Selected descriptions and those messages are included in full. Generated images and system messages are omitted.

Supports native macros such as {{char}}, {{user}} and {{description}}. Selected sources are available as {{ig_history}}, {{ig_character}}, {{ig_persona}}, {{ig_scenario}}, {{ig_personality}} and {{ig_examples}}. Native macros can include sources independently of the checkboxes.

Automation
Automatic imagesOff · generate only when you ask

One exact name per line, ignoring capitalization. Leave blank for any speaker in the chosen role. Works in solo and group chats.

Each automatic image uses your prompt writer and image provider. Counters belong to each chat and start from new messages. Greetings, swipes, continuations and generated images do not count. Pending triggers combine into the latest scene while a request is running.

ConfigurationExport or import your setup

Exports include prompts and rules, but no credentials or chat history. Importing turns automatic generation off until you enable it.
